# GITI BY SALEK HIGHTECH — Release Installer

The release installer contains only the compiled Windows VST3, standalone application and runtime assets. Repository source files are not copied into the installed product.

The built plugin includes a local 72-hour evaluation guard. This is an offline convenience trial, not a cryptographically secure licensing system; a commercial release should replace it with a signed license / activation service.
