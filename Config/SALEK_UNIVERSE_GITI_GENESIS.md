# SALEK UNIVERSE / GITI GENESIS

## فارسی — سند معماری هنری و مهندسی

### ۱. معماری کیهانی

**UNIVERSE / کیهان / گیتی**  
مجموعه‌ی مادر SALEK Universe است؛ یک جهان روایی که در آن ماشین‌های صوتی، نسل‌ها، منظومه‌ها، سیارات و قمرها به‌صورت سلسله‌مراتبی تعریف می‌شوند.

**GITI / گیتی — Generation 01**  
نخستین نسل ماشین‌های صوتی. تعداد Genesis محدود به **50 Edition شماره‌دار** است.

**KAYHAN / کیهان — Generation 02**  
نسل بعدی؛ ظرفیت پیشنهادی 100 واحد. این نسل دانش و تجربه‌ی GITI را به معماری کامل‌تر تبدیل می‌کند.

**MANZOOMEH / منظومه**  
مجموعه‌ای از چند Synth مرتبط که یک سیستم داستانی/صوتی را تشکیل می‌دهند.

**SIAREH / سیاره**  
هر سیاره یک شخصیت صوتی، طراحی و جهان کوچک مستقل دارد.

**GHAMAR / قمر**  
زیرمجموعه‌های سیارات؛ ابزارها، ماژول‌ها یا موجودات صوتی کوچک‌تر.

### ۲. اصل مهندسی GITI

هر GITI باید پنج لایه‌ی متفاوت داشته باشد:

1. **Identity DNA** — شناسه‌ی مستقل باینری، VST3 Plugin Code و Bundle ID.
2. **Sonic DNA** — پروفایل عددی پایدار برای طیف، هارمونیک، مدولاسیون، ترنزینت، فضا، خشونت صوتی، وزن پایین/بالا و بی‌ثباتی.
3. **Preset DNA** — بانک کارخانه‌ای همان Synth با مورفینگ محدود و موسیقایی متناسب با Sonic DNA.
4. **Visual DNA** — رنگ، نماد، نام، UI state و شخصیت تصویری.
5. **Lore DNA** — نقش، مأموریت و جایگاه آن موجود در تاریخ Universe.

تفاوت Edition نباید فقط در filename باشد.

### ۳. مدل Butterfly Effect

در مهندسی صدا، Butterfly Effect در GITI یک **مدل روایی/طراحی** است: تغییر کوچک و کنترل‌شده در پارامترهای صوتی می‌تواند رفتار شنیداری نهایی را تغییر دهد.

GITI از تغییرات bounded و deterministic استفاده می‌کند؛ یعنی یک Edition با یک ID مشخص، در هر build همان DNA را دریافت می‌کند و پارامترها از محدوده‌ی مجاز خارج نمی‌شوند.

این مفهوم یک ادعای علمی درباره‌ی ایجاد صلح یا کنترل رفتار انسان نیست؛ بخش مربوط به «صلح با یک سینت» متعلق به Lore و جهان هنری SALEK است.

### ۴. فرمان GITI

**اطاعت از فرمانده.**  
**برقراری صلح.**  
**بدون شلیک حتی یک گلوله.**  
**بدون ترس.**  
**بدون اضطراب.**  
**یک سیگنال.**  
**یک سینت.**

در Lore، این فرمان یک اصل تمدنی است: GITI قرار نیست با خشونت پیروز شود؛ مأموریتش ساختن نسل بعدی است.

### ۵. چرخه‌ی نسل

GITI برای جاودانه ماندن ساخته نشده است.

**GITI → learns → builds successor → transfers knowledge → shutdown**

خاموشی GITI نشانه‌ی شکست نیست؛ مرحله‌ی موفق انتقال نسل است.

در روایت، وقتی نسل بعدی بتواند از معماری دیجیتال به یک حضور واقعی/فیزیکی عبور کند، مأموریت GITI کامل شده است.

## English — Artistic & Engineering Architecture

### 1. Cosmic hierarchy

**UNIVERSE** is the parent architecture of the SALEK Universe.

**GITI — Generation 01**  
The First Generation of sonic machines: **50 numbered limited Genesis Editions**.

**KAYHAN — Generation 02**  
A proposed second generation of 100 units, inheriting knowledge from GITI.

**MANZOOMEH**  
A system of multiple related synthesizers with a shared narrative architecture.

**SIAREH**  
Planets. Each planet becomes an independent sonic character and design world.

**GHAMAR**  
Moons: smaller instruments, modules, entities or extensions belonging to a planet.

### 2. GITI engineering model

Every GITI is defined through five coupled layers:

- **Identity DNA** — independent binary identity, VST3 Plugin Code and Bundle ID.
- **Sonic DNA** — deterministic parameters controlling spectral focus, harmonicity, modulation, transient response, spatial behaviour, aggression, low/high weighting and instability.
- **Preset DNA** — edition-specific factory-preset morphing within safe musical parameter bounds.
- **Visual DNA** — palette, symbols, UI states and visual character.
- **Lore DNA** — role, mission and historical position inside the Universe.

An edition must not be a renamed copy.

### 3. The Butterfly Effect

Inside the GITI design language, the Butterfly Effect describes how a small, controlled change in a sound parameter can create a substantially different musical result.

The implementation is deterministic and bounded: the same Genesis ID always resolves to the same sonic genotype, while parameter values remain inside their engineered domains.

The peace/frequency mythology is intentionally treated as **fictional world-building**, not as a scientific claim that a synthesizer can control human behaviour.

### 4. The GITI Directive

**OBEY THE COMMANDER.**  
**ESTABLISH PEACE.**  
**NO BULLET.**  
**NO FEAR.**  
**NO ANXIETY.**  
**ONE SIGNAL.**  
**ONE SYNTH.**

### 5. Succession protocol

GITI is not designed to exist forever.

**GITI → learns → creates successor → transfers knowledge → shutdown**

When the next generation becomes capable of crossing from the digital architecture into the physical world, GITI completes its mission and shuts down.

The shutdown is not failure.

**It is successful succession.**
