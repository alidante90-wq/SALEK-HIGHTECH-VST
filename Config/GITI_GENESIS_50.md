# GITI — GENESIS 50

GITI is the first generation of the SALEK HighTech Digital Instrument Universe.

- 50 numbered Genesis editions: GITI-001 through GITI-050
- Edition identity is separate from software version.
- One codebase serves all editions through the GITI_EDITION_ID build definition.
- Future generations can use the same model: KAYHAN → MANZOOMEH → PLANETS → MOONS → STARS.
- NFT/blockchain is optional and external; the instrument does not depend on a wallet or chain.
- Software updates can preserve the edition identity. Example: **GENESIS #017 / Software v1.0.3**.

Each edition has a stable ID, name, element, archetype, BPM signature and visual palette. These are identity metadata, not investment or rarity guarantees.
